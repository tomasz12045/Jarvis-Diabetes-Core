# Epic 1: Środowisko i C++ Core Math

## Cel
Zbudowanie niezawodnego i energooszczędnego silnika w C++, który potrafi modelować krzywą wchłaniania insuliny i szukać 3 podobnych okienek. 

## Zadania Programistyczne (C++)
- [ ] **Task 1.1:** Implementacja równania Batemana (funkcja generująca krzywą wchłaniania insuliny bez sztywnych ram czasowych).
- [ ] **Task 1.2:** Stworzenie struktury danych dla logów i wdrożenie algorytmu liczącego matematyczny dystans (k-NN).
- [ ] **Task 1.3:** Logika Superpozycji - nakładanie na siebie dwóch niezależnych dawek insuliny w czasie (łączenie fal).
- [ ] **Task 1.4:** Przygotowanie funkcji do odbierania parametrów w formacie JSON z zewnętrznych aplikacji.

## Zadania Manualne (Konfiguracja)
- [ ] Utworzenie docelowego repozytorium na GitHubie z plikami i folderami.
- [ ] Konfiguracja prostego kompilatora C++ (np. GCC/Clang) do testowania logiki.
- [ ] Weryfikacja poprawności matematycznej algorytmu k-NN na ręcznie wpisanych, testowych plikach tekstowych.
