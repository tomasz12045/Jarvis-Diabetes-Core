# Smart Glasses & Sensory Input

## Cel
Docelowy moduł odpowiedzialny za peryferyjne, bezobsługowe zbieranie danych kontekstowych w tle, zwalniający użytkownika z konieczności wpisywania danych w telefonie.

## Ścieżki wejścia:
* **Obraz (Camera / ToF):** Rejestrowanie zdjęć posiłków w celu oceny objętości i makroskładników w chmurze (Computer Vision).
* **Dźwięk (Mic):** Przechwytywanie komend głosowych pacjenta (np. "Zjadłem jabłko") i przesyłanie ich jako strumień audio do agenta LLM w celu interpretacji intencji.
